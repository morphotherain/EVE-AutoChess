# 网页试玩版 · 构建与部署

> 记录时间：2026-11-04
> 现状：**斗地主**已能在线玩（`https://xshy.top/play/`）；自走棋本体暂未上网页，原因见第四节。

---

## 一、结论先放这

| 项 | 数字 |
|---|---|
| 首屏传输（gzip 后） | **≈ 30 MB**（wasm 9.7 MB + pck 19.9 MB） |
| 4 Mbps 服务器首屏耗时 | 约 **60 秒**，之后走浏览器缓存 |
| 导出方式 | Godot 4.7.2 **单线程** Web（`variant/thread_support=false`） |
| 证书 / 入口 | `https://xshy.top/play/`（同站，根目录 `/var/www/eve/play`） |

---

## 二、怎么打这个包

```bash
bash tools/build_web.sh            # 或 tools/build_web.sh <godot路径>
```

脚本干三件必须做的事（少一件就出问题）：

1. **主场景临时改成 `scenes/doudizhu.tscn`** —— Web 导出没有"每个预设一套主场景"这回事，
   只能改 `project.godot`，导完 `trap` 还原。
2. **临时删掉 `MCPRuntimeProbe` autoload** —— 它的脚本不在导出白名单里，
   留在包里启动即报 `Failed to load autoload`。
3. **`gzip -9 index.wasm`** —— Caddy 侧开了 `precompressed gzip`。

产物在 `build/web/`，八件：`index.html/.js/.pck/.wasm/.wasm.gz` + 三个图标/worker。

---

## 三、导出预设为什么长这样

`export_presets.cfg` 的 `[preset.3]`（名 `Web`）：

```ini
export_filter="scenes"
export_files=PackedStringArray("res://scenes/doudizhu.tscn")
include_filter="scripts/*, i18n/*, assets/fonts/*, assets/cards/*.png,
                assets/audio/sfx/*.ogg, assets/audio/ambience/*.ogg,
                assets/ui/*, assets/icon/*, assets/portraits/*,
                assets/backgrounds/caldari-c02-nebula-4096.png,
                assets/backgrounds/stars_layer_1920x1080.png"
```

⛔ **只写 `scenes` 模式会漏东西**，实测漏了三类：

| 漏的 | 症状 | 补法 |
|---|---|---|
| autoload 的脚本依赖 | `Parse Error: Preload file "res://scripts/core/eve_text.gd" does not exist` → 整页黑屏 | `scripts/*` 全带上 |
| i18n 翻译 | `Cannot open file 'res://i18n/strings.zh_CN.translation'` | `i18n/*` |
| 脚本里 preload 的背景图 | `Preload file "res://assets/backgrounds/caldari-*.png" does not exist` | 点名补两张 |

`export_filter="all_resources"` 也能跑通，但会把 161 MB 的 `assets/ships3d` 一起拉进来，
不划算。

## 四、自走棋本体现阶段上不了网页（数据说话）

| 目录 | 体积 | 网页版要不要 |
|---|---|---|
| `assets/ships3d` | **161 MB** | 要，战斗场景全靠它 |
| `assets/backgrounds` | 35 MB | 只要 2 张 |
| `assets/audio_candidates` | 31 MB | 不要（素材候选池） |
| `assets/audio` | 27 MB | 只要 sfx |
| `assets/vfx` / `video` / `ships` / `beacon` | 16 + 13 + 9.4 + 7 MB | 要 vfx，其余看场景 |

就算只用 gl_compatibility、压到极致，**舰船模型这一项就 161 MB**，
4 Mbps 的机器上等于 5 分钟以上首屏 —— 不可接受。

要真做，得先做资产治理：

1. `ships3d` 用 Draco/meshopt 量化 + 减面（161 MB → 目测 40~60 MB）
2. 贴图统一转 WebP / KTX2（`backgrounds` 那张 4096 星云 6.5 MB 就是典型）
3. 只导出试玩用到的 8~12 艘船
4. 分章加载（先下载 pck 的"壳"，模型按需拉）

**或者干脆别走 Godot Web**：把试玩做成纯 HTML/Canvas 的小切片（比如只做抽奖 + 布阵），
代价是两套代码，收益是首屏 1 MB 以内。

## 五、踩过的坑（都很贵）

### 1. 中文全是乱码

浏览器里没有"系统已装字体"这回事，`SystemFont` 退化成引擎自带默认字体（无中文字形）。
解法：随包分发 **Noto Sans SC 子集**（OFL 授权，`assets/fonts/` 两个文件各 616 KB）。

⛔ `ThemeDB.fallback_font = f` **单设不生效**；还得给根窗口挂 Theme：

```gdscript
var t := Theme.new()
t.default_font = f
get_tree().root.theme = t
```

⛔ 这段**不能放 `_init()`**：那时节点还没进树，直接报
`Parameter "data.tree" is null`，白干一轮（实测导了三次才发现）。

子集化脚本：`tools/pipeline/subset_font.py`，扫 `scripts/ scenes/ i18n/ data/ assets/ui/`
里出现的所有字符（含 csv 里的舰船名），2108 个字 → 616 KB。

### 2. 导出模板根本没有 web

本机只有 Android / Windows 模板。整包 `Godot_v4.7.2-stable_export_templates.tpz` 是 **1.2 GB**，
镜像 0.15~0.6 MB/s，还要先卡在 30 MB。

解法：`tools/pipeline/fetch_web_tpl.py` —— ZIP 的中央目录在文件尾，
用 HTTP Range 把 `web_*.zip`（`web` 与 `web_nothreads` 两套，共 6 个）单独抠出来，
只下 **~46 MB**。

⚠️ Godot 4.7 的非线程模板叫 `web_nothreads_*.zip`，`variant/thread_support=false` 时
只认这一套，两套都要。

### 3. 热更器在网页版刷跨域错误

`EveUpdater` 拉 `http://49.233.138.141/update/version.json`，跨域必被 CORS 拦。
网页版的包就是站点直接分发的，没有"本地热更"这回事 ⇒ `_ready()` 里
`if OS.has_feature("web"): set_process(false); return`。

### 4. 无头浏览器验证输入，别硬刚

`Page.captureScreenshot` 在画面无变化时返回同一帧（md5 一样），
`Input.dispatchMouseEvent` / `Input.dispatchTouchEvent` 注入到 Godot canvas 也不一定生效。
**结论：点击类交互只能让真人在真浏览器里点**，自动化只验证到"场景能加载 + 文字正常"。

### 5. 服务器拉 raw.githubusercontent 会间歇超时

2026-11-04 实测两次 40s timeout。一律改走
`https://gh-proxy.com/https://raw.githubusercontent.com/<owner>/<repo>/<sha>/<path>`。

## 六、部署步骤（服务器侧）

```bash
# 1. 拿包（走 GitHub Release + 镜像，别指望 ssh/scp，2026-11-04 起 22 端口握手被掐）
curl -fsSL 'https://gh-proxy.com/https://github.com/xshynews/EVE-AutoChess/releases/download/web-ddz-v1/web_ddz.zip' -o /tmp/play.zip

# 2. 解压（38 MB，别放前台，会超网关 30s）
mkdir -p /var/www/eve/play && cd /var/www/eve/play && nohup unzip -oq /tmp/play.zip > /tmp/unzip.log 2>&1 &
chown -R www-data:www-data /var/www/eve/play

# 3. Caddy 用 precompressed（见 deploy/Caddyfile），改完 reload
cp -a /etc/caddy/Caddyfile /etc/caddy/Caddyfile.bak-$(date +%Y%m%d)
caddy validate --config /tmp/Caddyfile.new --adapter caddyfile
systemctl reload caddy
```

验收：

```bash
curl -sI https://xshy.top/play/ | head -1                        # 200
curl -s -H 'Accept-Encoding: gzip' -o /dev/null \
     -w '%{size_download}\n' https://xshy.top/play/index.wasm     # 10084297（不是 38 MB 就对了）
```
