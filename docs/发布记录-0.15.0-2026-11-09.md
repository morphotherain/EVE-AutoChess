# 发布记录 · 0.15.0（2026-11-09）

> **重大更新**：新增独立玩法「**星舰万象棋**」，因此版本号从 `0.14.10.5` **升到 `0.15.0`**，
> 热更序号 `code` 从 `43` 递增到 `44`。
>
> 按项目既有惯例（见 `docs/发布记录-0.14.10.5-b26-2026-10-31.md`）：
> **小更新只递增 `code`，不升主版本**；本次是新增玩法，属于重大更新，故升主版本。

| 文件 | 原值 | 新值 |
|---|---|---|
| `project.godot` → `config/version` | `0.14.10.5.43` | `0.15.0` |
| `export_presets.cfg` → `version/name` | `0.14.10.5.43` | `0.15.0` |

**`code` 必须递增**：客户端 `EveUpdater` 只认 `code`，
`remote_code <= local_code` 就直接跳过（见 `scripts/core/eve_updater.gd:238`）。
只改 `version` 不改 `code` ⇒ 已装 0.14 的客户端**不会**收到这次热更。

运行时已验证：

```
application/config/version = 0.15.0
build_info() = { "version": "0.15.0", "code": 44 }
```

> `build/` 与 `android/build/` 下的 `version.json` 是**导出产物**，
> 由 `tools/publish_hotfix.sh` / `export_release.sh` 自动重写，**不手动改**。

## 二、这一版玩家能感觉到什么

**主菜单最上方多了一项「星舰万象棋」**，点击后右侧出现「标准 6 人局」卡片，
点开始进入 6 人自走棋对局。

它不是外挂的小游戏，而是**复用本工程全部美资产**的独立玩法：

- **52 艘舰船全部可用**，直接读 `scripts/data/eve_ship_table.gd` 的权威数据
- **商店卡面用的是官方 1024px 渲染立绘**（`assets/ships/*.png`）
- 按钮 / 字体 / 配色全部沿用本工程（`EveButtonTheme` / `FONT` / 四帝国色）

也就是说：**自走棋那边改舰船平衡，星舰万象棋会同步生效**，不存在两份数据。

## 三、星舰万象棋做了什么

### 主菜单接入（`scripts/eve_main_menu.gd`，共 3 处）

1. 常量 `STAR_CHESS_MODE_ID` / `STAR_CHESS_SCENE`
2. `_build_top_table()` 里在 `EXTRA_MODES` 循环**之前** `out.append(...)`
   —— `_modes` 的顺序就是左列渲染顺序，插在前面才是第一项
3. `target_scene_for_start()` 分支返回 `STAR_CHESS_SCENE`，放在 `tier_id` 之前

### 新增文件

```
scripts/starchess/
  sc_context.gd      autoload：场景间传参
  sc_ship_adapter.gd 船表翻译层（EveShipTable.ROWS -> 自走棋卡池）
  sc_shop_card.gd    顶部商店大卡（复用 EveShipArtView 画真立绘）
  sc_lobby.gd        选指挥官（6 人环 / 60s / 可重复选）
  sc_battle.gd       对局主界面
  sc_over.gd         结算
  README.md          模块说明
scenes/starchess/    sc_lobby / sc_battle / sc_over
data/starchess/      sc_commanders.json
tools/               verify_starchess / probe_starchess_adapter / probe_starchess_shot
```

### 玩法要点（与真实游戏对齐）

- 6 人局，起始 60 血
- 选指挥官 **60 秒**，**可以重复选**
- 商店 **4 格**、**固定 3 费**、**首次刷新免费**、之后 1 费
- 同名舰船 **合流 +3 级**
- 上阵上限随等级 3→8

## 五、已知缺口（本版**未**解决）

1. **战斗内核很粗**：目前 `战力 = Σ(atk × level)`，血量 / 护盾 / 射程 / 攻速 / 流派都不参与。
   能证明按钮通到下一回合，但**算不出合理胜负**。
2. **六流派只有名字**，没有真实触发效果。
3. **5 个 AI 敌人没有自己的阵容**，只有血量变化。
4. **棋盘样式**是占位（明确标注「未实现」）。
5. **战斗表现**是文字日志，没有逐舰演出。

> 这些都是下一轮的事。详细的玩法策划案正在另行编写。

## 六、回滚

版本号改动前的三个文件备份在工程根目录：

```
project.godot.bak-bump-20261109-210702
build_info.json.bak-bump-20261109-210702
export_presets.cfg.bak-bump-20261109-210702
```

星舰万象棋是**纯加法**（没删没改 EVE 既有玩法），
紧急回滚只需把 `_build_top_table()` 里那一段 `out.append(...)` 注释掉，
再把版本号退回 `0.14.10.5.43` / `code = 43`。
