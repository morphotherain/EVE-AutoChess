# 界面音效

`selection.json` 保存已选定的 45 个语义槽位和 38 个独立声音。`clips/` 仅包含实际选中的 EVE 原始媒体；原事件名、媒体 ID 和来源散列保留在配置中。

`EveUiAudio` 根据实际界面操作或阶段事件播放，复用游戏的 Master、SFX 和 Ambience 总线。配置中的 `playback_gain_db` 保留选音时确定的响度补偿及额外增益，槽位自己的 `gain_db` 单独叠加；媒体音高和时长不变。

播放器跨窗口与场景保留。相同操作的语义音效与通用点击声去重，短时间重复请求沿用节流。没有右下角槽位提示、播放历史或试听开关。
